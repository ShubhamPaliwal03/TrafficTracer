CICFlowMeter Guide

Follow these steps:

  1. Download the CICFlowMeter.zip file.
  2. Extract it anywhere on your PC.
  3. Navigate to /bin and double-click CICFlowMeter.bat.
  4. Load your .pcap file and export it as .csv.

Video Tutorial:

Prerequisites:

  • Java 1.8: Download Java 1.8
  • Install Java and ensure it’s in your PATH (check by running java -version in terminal).
